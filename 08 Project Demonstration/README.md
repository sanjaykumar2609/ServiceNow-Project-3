# Phase 8 – Project Demonstration

## Project Title

Implement Client Script & UI Policy (Incident)

## Technology

ServiceNow

## Demonstration Overview

The project demonstration presents the implementation and working of UI Policies and Client Scripts on the ServiceNow Incident table.

The demonstration explains the project purpose, implemented features, testing process, and final results.

## Demonstration Contents

The demonstration video covers the following:

1. Project title and introduction.
2. Project purpose and objective.
3. ServiceNow Incident table.
4. High Impact Control UI Policy.
5. Urgency UI Policy Action.
6. Auto set urgency for high impact onChange Client Script.
7. Prevent save if Assigned To missing onSubmit Client Script.
8. Prevent state change via list edit onCellEdit Client Script.
9. Testing of the implemented features.
10. Final project result.

## Working Process

The demonstration shows the following workflow:

Incident Form → Select High Impact → Apply UI Policy → Set Urgency to High → Validate Assigned To → Submit Incident

The demonstration also shows the restriction of State changes through direct list editing.

## Demonstration Video

The final demonstration video will be recorded with:

- Laptop screen sharing
- Student voice-over
- No face camera required
- ServiceNow project walkthrough
- Configuration and testing demonstration

## Benefits

The implemented configuration provides:

- Conditional Incident field behavior
- Automatic Urgency updates
- Assigned To validation
- Restriction of State changes through list editing
- Improved Incident data consistency

## Final Output

The completed ServiceNow Incident configuration demonstrates the working behavior of the implemented UI Policy and Client Scripts.
