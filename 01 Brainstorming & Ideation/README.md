# Phase 1 – Brainstorming & Ideation

## Project Title
Implement Client Script & UI Policy (Incident)

## Technology
ServiceNow

## Project Idea
The project focuses on improving Incident form behavior and data consistency using ServiceNow UI Policies and Client Scripts.

## Main Idea
The system should:
- Control Incident field behavior based on conditions.
- Automatically set Urgency when Impact is High.
- Validate Assigned To before saving a High Impact Incident.
- Prevent State changes through direct list editing.

## Proposed Solution
Use ServiceNow UI Policies and Client Scripts to provide conditional field behavior, automatic updates, and client-side validation.
